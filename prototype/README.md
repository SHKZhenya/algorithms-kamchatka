# Синтетический прототип

```bash
python3 -m unittest discover -s prototype -v
python3 prototype/simulate.py
```

Зависимости — Python 3, NumPy и Matplotlib. Проверено с NumPy 2.4.4 и Matplotlib 3.10.9. Параметр `--output` задаёт каталог результатов. Значения воспроизводятся по фиксированным seed, кроме измеренного времени расчёта.

Четыре восьмичасовых синтетических события на графе из 24 направленных рёбер, три плуга, два коридора, шаг 15 минут. Для каждого события — контроль, смещения прогноза −35% и +35%, пропуски наблюдений с вероятностью 35% и комбинация занижения прогноза с пропусками. Архив синтетических выпусков строится из сценарной погоды со сглаживанием, смещением и шумом. Адаптивные методы оценивают по 128 допустимых маршрутов за вызов с горизонтом до 2 часов. B0 делает один расчёт на все 8 часов с 128 маршрутами. Позиция машины переносится между интервалами, маршруты возвращаются в депо. На шаге допускается один эффективный проход по ребру. Одновременные проходы оплачиваются каждый. Стоимость прохода — 1 усл. ед., холостого перемещения — 0,55, ожидания — 0.

Модель среды использует иные коэффициенты перехода снег → лёд, таяния и эффективности снятия, чем модель прогноза. Убранный снег пополняет вал; часть массы уходит за пределы учёта. Разрушение льда, вывоз, реальные повороты и распределение времени на участках здесь отсутствуют. Видимость — сценарный внешний множитель, известный для предыдущего шага и фиксируемый на горизонте оценки. Показатели измеряются в конце шага. Для пропускной способности берётся минимум сечений фиксированного коридора. Конкуренция поворотных потоков и OD-спрос сюда не входят.

Порядок выбора кандидатов — минимальный slack прокси безопасности, затем максимального отклонения по коридорам, затем стоимость. Допуски в сценарии — до 1 усреднённого по рёбрам прокси-часа превышения и до 25% времени ниже 65% сухого эталона в каждом коридоре. Адаптивные стратегии используют общую оценку уже накопленных нарушений. Случайная выборка маршрутов и ограниченный горизонт не дают сертификата оптимальности или невыполнимости. Прогон является демонстрацией протокола и не включает независимую калибровку, отказ машины, оттепель или проверку чувствительности к шагу.

## Результаты

**H1, искусственные наблюдения без уборки.** В контроле средняя MAE на 60 мин составила 0,116 кг/м² для снега и 0,081 для льда у B2, против 0,600 и 0,278 у B1, 0,458 и 0,278 у B1-W. При заниженном прогнозе B1-W показал немного меньшую ошибку по снегу, чем B2 (0,220 против 0,223 кг/м²), а при занижении с пропусками разница выросла (0,255 против 0,286). Прогнозы здесь проверены в среде с теми же типами переходов, поэтому это проверка механики эксперимента. Ошибки по каждому событию и горизонту сохранены в [forecast_mae.csv](results/forecast_mae.csv).

**H2, управление.** Средние для четырёх событий в контроле:

| Метод | Стоимость, усл. ед. | Часы превышения прокси | Коридор 1 ниже порога | Коридор 2 ниже порога |
|---|---:|---:|---:|---:|
| B0 | 0,00 | 10,49 | 69,5% | 68,8% |
| B1 | 47,29 | 5,78 | 64,8% | 68,8% |
| B1-W | 54,76 | 5,23 | 60,2% | 67,2% |
| B2 | 56,81 | 5,10 | 62,5% | 65,6% |

Из 20 пар B2–B1 прокси улучшился в 19, стоимость выросла во всех (дельта от +1,75 до +16,85). Из 20 пар B2–B1-W прокси улучшился в 18, стоимость уменьшилась в 5 (дельта от −1,55 до +5,35). Это диапазоны сценарной чувствительности. Пять вариантов одного события зависимы. Правила качества одновременно не выполнила ни одна стратегия ни в одном прогоне. B0 для выбранных начальных состояний и ограничений выбирает ожидание. Результат указывает на обмен затрат на снижение модельного индекса и оставляет гипотезу об экономии при одинаковом качестве открытой.
