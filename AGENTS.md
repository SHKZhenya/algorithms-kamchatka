# Алгоритмы Камчатки

Перед первой содержательной задачей обязательно прочитай [инструкцию по Git и публикации](GIT_INSTRUCTIONS.md). Все изменения проекта в итоге должны передаваться в публичный репозиторий Жени `SHKZhenya/algorithms-kamchatka`. Соблюдай указанные в инструкции границы конкретного поручения пользователя.

Перед первой содержательной задачей прочитай [базу знаний проекта](KNOWLEDGE_BASE.md). Используй её ссылки на локальные отчёты, данные и исходные чаты по теме задачи. Если нужен свежий статус или недостающее подтверждение, проверяй конкретный пробел. Сохраняй в базе новые выводы с датой, источником и статусом проверки.
