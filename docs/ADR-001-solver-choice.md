# ADR 001 · Решатель для очистки

**Принято 19.11.2026.** Для первого пилота использовать локальный роутинг NetworkX, жадную политику B0 и O1 как адаптер SciPy/HiGHS. Контракт принимает раскрытые направленные действия от любого решателя. B0 остаётся резервным путём и входит в пул O1. Сравнение специализированных CARP-движков на одних и тех же развёрнутых маршрутах требует транслятора ограничения → формат движка → независимый replay.

Каждая колонка O1 — полный маршрут конкретной машины с соблюдением окон, смены и возврата. Для задачи и машины допускается максимум одна выбранная колонка. После максимизации числа покрытых задач по каждому классу приоритета фиксируем достигнутые значения и минимизируем переменную стоимость. Пул составлен из B0, соседних перестановок его заданий, одиночных задач и жадных прогонов с детерминированной псевдослучайной выборкой по seed. Единица покрытия — полностью выполненное задание со всеми проходами.

Ограниченный пул даёт проверяемый результат быстро. Оптимальность относится только к этому пулу, который не перечисляет все маршруты. При остановке сохраняется лучший целочисленный обнаруженный кандидат, оценённый по той же лексикографической цели. Сравнение качества решения с внешними CARP-движками отложено до общего справочника машин и ограничений. Для этапа вывоза PyVRP и CP-SAT прошли раздельные smoke-тесты, схема синхронизации остаётся отдельной задачей.
