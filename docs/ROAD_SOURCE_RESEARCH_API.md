# Импорт дорожных источников и отдельный read-side API

22 ноября 2026 года. [Численный отчёт об источниках](../research/geodata-accessibility-2026-11-22/SOURCE_REPORT.md).
[Исследование фасадов](../research/geodata-accessibility-2026-11-22/FACADE_REPORT.md).

Импорт не меняет CityData, узлы/рёбра маршрутизатора, действующую модель фасадов
или правила допуска техники. Источники сохраняются отдельным слоем. Наличие
официальной паспортной ширины не означает свежего измерения или доступной зимней
ширины. Историческое ограничение не применяется как действующее автоматически.

## Получение данных

Для исследовательских загрузчиков дополнительно нужны `requests` и `pyarrow`;
они не импортируются при обычном запуске backend. Весь доступ анонимный:
используются публичный `/api/v3/portal` и схема `gis_api_public` СКДФ,
доступная его карте. Закрытые схемы, пользовательские токены и операции записи
не используются. Ответы кешируются в указанной локальной папке.

```sh
python -m city_sim.download_road_sources --source skdf --output out/road-sources
python -m city_sim.download_road_sources --source overture --output out/road-sources
python -m city_sim.import_road_sources --sources out/road-sources --output out/road-import
```

Загрузчик СКДФ получает все 199 записей владельца 2794864 — администрации ПКГО,
затем карточки, геометрию и заполненные блоки частей дорог: roadway, lanes,
pavement, km-posts, sidewalks, barrier-fences, clearances, gabarit,
median-separations. Также постранично скачивается публичный региональный реестр
Камчатского края, кешируется в `skdf-region-all.json` и проверяется на полноту/
дубликаты. Добавляются названия региональных/федеральных дорог, содержащие
Петропавловск. В выполненном исследовании это ещё 24 записи. Это целевая
выборка и не объявляется всей сетью города.

Overture закреплён на релизе `2026-11-18.0`. STAC/GeoParquet читаются HTTP Range,
по статистикам bbox выбираются row groups. Скачивается полный bbox условной
OSM-границы `relation/4139922`, затем импорт отбирает пересечение с полигоном.
Это отличается от старого расчётного bbox, отрезавшего восток/юг границы.

Импорт работает офлайн по сохранённым файлам. Результаты:

- `road-evidence.geojson`: локализованные значения и отдельно `contexts`;
- `results.json`: покрытие, прирост относительно OSM, причины отбрасывания,
  все сопоставления и исходные паспортные интервалы;
- `overture-city.geojson`: исходные городские сегменты для отдельной проверки.

## Правила сопоставления

Overture сопоставляется по исходному OSM way ID и геометрии. Линейные интервалы
`between` и `sources[].between` пересекаются; частичное значение не растягивается
на весь way. Требуется не менее 80% согласования исходной поддержки в полосе 3 м.
Несогласованные версии остаются в аудите.

Для СКДФ требуется нормализованное название и не менее 80% геометрического
согласования OSM-линии в полосе 8 м; для А‑401 также используется явный ref.
Полоса — исследовательский порог сопоставления, не точность съёмки.
Паспорт автодороги не назначает ширину параллельному пешему way.
Неоднозначные параллельные односторонние проезжие части сохраняются с
`carriageway_assignment_ambiguous=true` и не увеличивают подтверждённое покрытие.

Ширина читается только из `roadway_width`. `square/length` не используется.
На весь соответствующий участок переносится лишь постоянное значение,
покрывающее полную официальную часть дороги. Для меняющихся ширин нужны
геопривязанные официальные километровые столбы: близость ≤20 м к линии,
не менее трёх столбов, монотонный порядок, отношение длины геометрии к
километражу 0,7–1,3. Границы интервала интерполируются только между этими
опорами, без экстраполяции и пропорционального растягивания всей дороги.
Качество привязки записано в `anchor_quality`; это производная локализация.

## Подключение к API

По умолчанию новый слой отключён. Чтобы открыть подготовленный файл:

```sh
CITY_SIM_ROAD_EVIDENCE=out/road-import/road-evidence.geojson python -m city_sim
```

Условия повторного использования СКДФ для публикации/коммерческого применения
не подтверждены: приведённая команда предназначена для локального исследования.

`GET /api/v1/registry/road-evidence?bbox=w,s,e,n&way_id=osm:way:…`

Для `bbox` действует прежний валидатор доступной области CityData
(`158.48,52.91,158.80,53.16`). Полный полигональный срез Overture также сохранён
офлайн; область работающего приложения этим исследованием не расширялась.

Ответ — GeoJSON `features` и массив `contexts`. Без настройки возвращается
пустой слой с `status=not_configured`. Недоступный файл — 503, неверная схема —
422, чужая ревизия OSM — 409. Кеш зависит от пути, SHA256 и ревизии.

Каждое локализованное значение содержит источник, лицензию/неопределённость прав,
класс `cartographic|official_inventory|design|estimated|field_measured`,
`quantity`, `value`, OSM way ID, исходный ID/паспорт, геометрию поддержки,
статус сопоставления и ограничения. В этой поставке полевых измерений нет.
`local_scope_verified` означает пройденное правило сопоставления источников,
а **не проверенную натурную точность**; `field_verified=false` сохраняется.

`contexts` сохраняет записи о тротуарах, ограждениях и габаритах, когда точная
локальная поддержка не установлена. `osm_way_ids` — геометрически сопоставленная
дорога; `candidate_osm_way_ids` — только кандидаты по названию. Проверяйте
`road_association`. Ширина тротуара не превращается в ширину проезжей части,
а дорожное ограждение не считается пересекающей путь стеной автоматически.
Ссылка на временный приказ 2024 года остаётся историческим/непроверенным
свидетельством, не текущим запретом 2026 года.

Ни этот API, ни импорт не создают подтверждённых входов, топологических связей
или событий уборки. Имеющийся `/registry/road-widths` по-прежнему описывает
OSM/baseline; новый слой не подменяет его незаметно.

## Проверки

```sh
python -m unittest city_sim.tests.test_road_sources
python -m unittest discover -s city_sim/tests
python -m unittest discover -s tests
```

Проверяются линейные диапазоны и геометрия Overture, запрет вывода ширины из
площади, неполные/меняющиеся интервалы СКДФ, привязка к километровым опорам,
отсутствие переноса автомобильной ширины на пеший way, источник/ревизия,
разделение контекста и локальных значений, неизменность графа и слепота
экспериментальных признаков к тегам входа.
