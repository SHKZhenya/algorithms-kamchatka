Проверены `city_sim/api.py`, `geodata.py`, `city_snow.py`, `snow_experiment.py`,
`web/`, `README_CITY_SIM.md`, база знаний и локальные снимки OSM.
FastAPI уже отделён от MapLibre; SQLite хранит сценарии, файлы NPZ/JSON — расчёты.

Рейтинг дорог вычисляется на сервере, адресного рейтинга и точек входов нет.

## Принятые решения

1. Светлая полноэкранная карта, плавающая полупрозрачная панель сценария слева,
   список объектов справа, временная шкала внизу, карточка по выбору.
   На узком экране переключение сценария и списка. Инструменты геоданных,
   сценарии ветра, исторические точки, отчёты и слои сохраняются.
2. Серверный каталог доступа из реальных OSM-узлов и линий. Пешеходные пути
   отдельно от автомобильных, запреты доступа сохранены. Никаких дорисованных
   связей. Компоненты по общим узлам OSM; ближайшая линия — только кандидат,
   а не доказанная связь. Допуск спецтехники остаётся неподтверждённым.
3. Серверный рейтинг по сохранённому полю конкретного run/frame. На входах
   пробы снаружи стены, у здания сравнение сторон; сохраняются координата
   пробы, размер ячейки и расстояние. Неопределённость не заменяется процентом.
4. Сортировка по свежему снегу, неизвестные в конце. Эксплуатационный приоритет
   отдельный; экспериментальный порог 20 см настраивается без пересчёта физики.
5. API каталога/дорог/качества по bbox, рейтинг с пагинацией, проверкой run/frame
   и revision. Frontend только управляет и отображает полученные значения.

## Проверка

Синтетические геометрические тесты связей и ограничений; NPZ-поля с известными
значениями для рейтинга, пропусков и кадров; реальный разворот ветра 270°/90°;
прежние тесты; браузерный сценарий, переход к объекту, перемотка, мобильная
компоновка и отсутствие ошибок. Итоговые результаты — в `REPORT.md`.
