# Backend: аудит и план, 22 ноября 2026

AccessCatalog уже читает OSM service/footway/steps и входы, хранит общие узлы и компоненты. CitySnow сохраняет численные поля, временные кадры и погодные входы. Новый сервис и повторный импорт графа не нужны. Старые городские рейтинги основаны на середине сегмента и смешанном индексе; здания без известных входов не представлены в реестре доступности.

Данил: main 75bc8ecfdc04d72c0a0eb0ea4a25398940125eaa, clearance.py проверен через GitHub 22.11.2026. Внешний CSV содержит реальные точки с point_source=osm_node, но в репозитории отсутствует. Физическое ядро остаётся закреплено на 087118ff. Новая оценка не меняет физику.

Последовательность:

1. Реестр зданий, входов и подходов с неизвестными входами, ориентацией и происхождением.
2. Дорожная и пешая OSM топология, ограничения; без выдуманных соединений.
3. Поддержка CSV Данила с проверкой источника и координат.
4. Оценка линий/областей по пересечениям ячеек: среднее/P90, превышения и геометрия, покрытие, baseline.
5. Раздельные воздействие, значимость и качество, объяснимый порядок проверки.
6. FastAPI, погода сценария, тесты, пилот и городское покрытие.
