# Первый парный эксперимент на OSM

19.11.2026. Центральный участок Петропавловска-Камчатского. Seed 42, 24 направленных задания, 28 проходов. B0 выбирает ближайшее допустимое задание высшего доступного приоритета. O1 выбирает комбинацию раскрытых маршрутов, сформированных на том же снимке. Все результаты прошли проверку непрерывности, направления, поворотов, окон и смен. Недовыполнение обязательных проходов сохранено в планах как нарушение.

В базе сервисный пробег у обоих 2,358 км. Холостой пробег с возвратом снизился с 11,462 до 11,226 км, суммарное время техники с 2 653 до 2 619 с. Использованы 2 из 3 машин в обоих планах. O1 подтвердил оптимальность внутри 150 кандидатных маршрутов. В укороченной смене O1 пропустил 6 заданий против 9 у B0. Оба пропустили по одному приоритетному заданию. При дедлайне 400 с четыре приоритетных задания остались невыполненными у обоих. Глобальная допустимость для этих двух случаев неизвестна.

При двухминутной смене полное обслуживание математически невозможно в модели. Даже без переездов требуется 719 с чистого сервиса при бюджете 120 с. Этот сертификат рассчитан отдельно от поиска.

У методов общий снимок внутри каждой пары, лимит 30 с на метод и одинаковая независимая проверка. O1 завершился за 0,29–12,40 с. Время адаптера включает подготовку маршрутов и решение, время импорта измерено отдельно. Вывод о стоимости ограничен синтетическими тарифами, заданным набором работы и выбранным участком. Фиксированные затраты, пропускная способность, риск ДТП и площадь уборки неизвестны. Числа показывают сценарную чувствительность, выборка из этих шести кейсов не оценивает городской эффект.

Команды запуска приведены в [README](../README.md). Исходы по каждому методу с разложением стоимости находятся в `out/pkc-first/metrics.csv`, развёрнутые маршруты — в `out/pkc-first/<сценарий>/`. Переменная стоимость сравнивается только при полном покрытии у обеих политик.

Повторный базовый запуск дал побайтно одинаковые вход, два плана JSON и два слоя GeoJSON. Для всех 12 планов из полного запуска повторены проверка действий и расчёт стоимости из исходных тарифов. Проверена контрольная сумма OSM-снимка.
