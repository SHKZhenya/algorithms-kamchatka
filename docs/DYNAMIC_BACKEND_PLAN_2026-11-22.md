# Динамический backend: аудит и последовательность

22 ноября 2026. Новое поручение продолжает промежуточный объектный этап.
UI, публикация и развёртывание исключены.

Аудит: старый CitySnow 087118ff — эмпирическое осаждение нового снега, без состояния.
Прототип prototype/simulate.py ведёт баланс на синтетическом графе, но ветровой
пространственный обмен не реализует. Реестр входов содержит 1331 точку, 64 без
здания; чтение OSM не включает независимую актуальную выгрузку entrance/part.
Оценки пропусков до сих пор не разделяют причины. Существующие API оставляем.

Последовательность:

1. Поиск CSV и новых OSM-источников, отдельный снимок и журнал проверенных источников.
2. Новое сопоставление по принадлежности узла контурам/частям и геометрии,
   отдельные кандидаты по реальным окончаниям пеших линий, без выдуманных связей.
3. Консервативная пространственная схема баланса кг/м²: рыхлый/связанный запас,
   осадки, ветровые потоки через грани, явные граничные потоки. Отдельная версия.
4. Уборка как перенос в заданную область вала/вывоз с учётом доступной массы;
   история, подтверждения, дедупликация и детерминированное воспроизведение.
5. API состояния/погоды/уборки/истории и ранжирование по вычисленному состоянию.
6. Классификация и исправление пропусков, пилот и городские сквозные эксперименты,
   разрешение, baseline, численные критерии баланса и прежние регрессии.

Основа переноса: уравнение непрерывности со снегозапасом и потоками (SnowTran-3D),
пороговое трение и ограниченная доступным рыхлым снегом ёмкость сальтации Pomeroy–Gray.
Это сокращённая исследовательская модель, не реализация всего SnowTran/Crocus.
Коэффициенты и ветер около зданий требуют самостоятельной проверки; строгий
дискретный баланс не означает доказанную точность пространственного прогноза.

Реализация и сквозная проверка завершены для заявленного исследовательского
варианта. [Численные результаты, источники и остающиеся измерительные пробелы](../research/dynamic-backend-2026-11-22/REPORT.md).
