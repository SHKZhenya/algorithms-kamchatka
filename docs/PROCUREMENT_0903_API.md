## API

- `GET /api/v1/procurement/0903/objects?kind=intraquarter&object_id=0903:intraquarter:03` — документальные объекты, ссылка на таблицу и строку обоих DOCX, текстовые ориентиры, кандидаты named OSM way. Параметры необязательны.
- `GET /api/v1/procurement/0903/works` — 1 042 позиции с исходными единицами, ценой DOCX, характеристиками, годом в тексте и годом по последовательности сметных разделов. `quantity=null`: фактическая заявка отсутствует. Ссылка `estimate_reference` позволяет сравнить XLSX.
- `GET /api/v1/procurement/0903/routes?object_id=0903:intraquarter:03` — GeoJSON кандидатов линий, последовательность существующих OSM node edges, пропуски и степень покрытия ориентиров. Это не полигоны содержания.
- `GET /api/v1/procurement/0903/anchors` — все 25 интерпретаций описаний; кандидаты адресов/названий, расстояние привязки и неразрешённые ориентиры.
- `POST /api/v1/procurement/0903/candidate-assessment` — `{candidate_id, profile, valid_at, operation: "transit"|"clear", territory_id?, frame?}`. Профиль берётся из существующего `/api/v1/equipment/profiles`. В ответе — существующая трёхзначная оценка техники, причины, состояние снега и ограничения документального слоя. Время должно совпадать с кадром снега. Частичные маршруты отклоняются с 422, неизвестный кандидат — 404, другая версия графа/снега — 409. `frame` требует `territory_id`.

Для проверки действующего городского снимка используются артефакты в `city_sim/data/procurement-0903`; они попадают в существующую Docker-сборку через `COPY city_sim/data`. ## Семантика

`service_boundary_confirmed=false`, `operational_authorization=false`. Сходство адресов, близость здания или связный путь OSM не устанавливают границу содержания, точный вход или допуск техники. Ширина прохода уборки задаётся явно только в сценарии. Ценовые единицы 1 000 м², км вала, м³ и тонна не взаимозаменяемы без независимых данных площади/плотности/массы.

Сопоставление маршрутов использует ориентиры в порядке описания, локальные кратчайшие пути по существующим узлам и до трёх вариантов. Адресные центры привязываются не дальше 120 м, для поиска пути используется запас 300 м. Это параметры поиска, не доверительные интервалы. Для named street выбирается локальный узел относительно соседнего адресного ориентира. Для «между домами» используется промежуточный ориентир с сохранением обоих адресов. Условия «за домами», «к воротам», «подъём», «поворот», «конечная» требуют просмотра; кандидаты могут проходить вне описываемой территории. OSM-ограничения, снег и манёвр оцениваются существующим EquipmentAccess, допуск не выводится из наличия лота.

```sh

python -m unittest discover -s city_sim/tests
```

Подпись `.sig` сохранена, криптографическая действительность подписи не проверялась. Скрипты воспроизведения используют исследовательскую папку только для чтения/записи результатов и генерируют компактный runtime-слой; API не исполняет инструкции документов.
