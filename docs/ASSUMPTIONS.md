# Допущения первого среза

| Значение | Источник | Влияние на вывод |
|---|---|---|
| Два приоритетных коридора | `assumed`, выбор для пилота | Дедлайн 900 с в базе и 400 с в стресс-кейсе. Официальный статус требует подтверждения |
| 24 задачи, 28 проходов | `synthetic`, seed 42 | Семь дуг на каждом из двух коридоров, по пять на двух остальных улицах. Первая дуга на каждой улице требует двух проходов |
| Парк, депо, смены, скорости | `synthetic`, максимум 25 км/ч транзит и 12 км/ч сервис | Депо виртуальные. База 3 машины по 25 мин, ограниченные смены намеренно короткие для различимого стресс-теста |
| Допуск плуга на дугах без тегов запрета | `assumed` | Неизвестные уклоны, ширина, зимняя проходимость и манёвры нуждаются в полевой сверке |
| 120 руб./км транзит, 170 руб./км сервис, 0,18 руб./с времени | `synthetic` | Раздельные сценарные статьи. Ставки на км представляют расход по пробегу, ставка времени отдельна. Фиксированные расходы неизвестны |
| Погода, сцепление, ДТП и пропускная способность | Неизвестны для снимка | План выполняет фиксированные задания. Экологический, транспортный и бюджетный эффект по пилоту не оценён |

Список недостающих данных и предполагаемых владельцев ведётся в `data_gap_register.csv`.
