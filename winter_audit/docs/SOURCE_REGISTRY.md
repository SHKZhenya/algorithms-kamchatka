# Происхождение данных

Машиночитаемый каталог `tables/sources.csv` содержит ссылки, реквизиты, способ извлечения, область утверждения и дату публичной проверки. Для OSM фактические URL и времена трёх тайлов в `data/pkc/scale-manifest.json`. Для каждого объекта геометрический локатор — тип объекта и OSM ID, для действующей обязанности нужен локатор пункта и приложения с объектом. Архивная редакция, закономерность, сообщение СМИ, вычисление и сценарий имеют собственные уровни подтверждения. Поля без источника отсутствуют или равны null, а исходные теги OSM хранятся с оригинальными единицами.

В архив включена копия DOC регионального перечня с сайта органа. SHA-256 `728ea6e43f5de71be50ff89a08e34d38578c5c41931e32b358d0949b52969dc7`. Таблица получена из строк Word через textutil и разбор HTML-ячеек; разделители десятичных чисел нормализованы. Срок действия на ноябрь 2026 по одной версии на 01.01.2024 не устанавливается. [Сайт органа](https://avtodor41.ru/files/roads)

Правила № 170-нд проверены по официально размещённой копии. SHA-256 PDF `3ffe8954ad48068c160a2747d400122bc08d9cef064157d661f748b4b03dfe1c`. Для текста и изменений переходите по городскому порталу. [Городская копия](https://www.pkgo.ru/upload/medialibrary/a37/sm1cs86gmv4q2fo7n0isrps8hbsk8dh6.pdf)
