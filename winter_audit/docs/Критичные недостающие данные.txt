Критичные недостающие данные для дорожного аудита Петропавловска-Камчатского
Срез на 20.11.2026

1. Подписанные территориальные приложения по зимнему содержанию

   Нужны действующие редакции приложений к контракту № 3410114343626000068 (закупка № 0831) и договору по закупке № 0951 от 03.01.2026. Достаточно выписок по участкам пилота с границами «от и до», видом работ и периодом действия. Если приложение менялось, нужна редакция, действовавшая на проверяемую дату.

   По № 0831 установлены стороны договора и 18 позиций извещения. Подписанное приложение нужно, чтобы закрепить за подрядчиком конкретный вид работ на конкретном участке. Для проверки возможного дублирования с № 0902 понадобится такое же приложение после заключения договора. На дату среза по № 0902 доступно извещение с приёмом заявок до 30.11.2026.

2. Пообъектный перечень 549 проездов

   Нужен официальный список исключённых объектов с датой изменения и реквизитами решения. По каждой позиции достаточно адреса с однозначными границами, координат либо схемы. Если отдельного списка исключённых нет, подойдут две редакции перечня, по которым можно восстановить исключения. Сведения о новом ответственном нужны отдельно по каждому объекту, где такое назначение сделано.

   Без этого нельзя установить, какие сегменты исключены из муниципального обслуживания и где после изменения документально подтверждён исполнитель.

3. Действующие дорожные ограничения на выбранных участках пилота

   Для допуска реальной техники нужны схемы движения, данные владельца дороги о знаках или подтверждённая полевая проверка. Для закрытий нужны границы, направление, срок и исключения. Для мостов и других сооружений нужен точный тип ограничения и порог: полная масса, нагрузка на ось или габарит. Для проверки по конкретной машине нужны её рабочая масса и осевые нагрузки с оборудованием и загрузкой. Если уклон используется как запрет допуска, нужны проверенный профиль участка и допустимый уклон для этой машины в заданных зимних условиях.

   Эти сведения нужны для диспетчеризации. Расчёт чувствительности на 360 заданиях уже выполнен на сценарных параметрах. Для него дополнительных данных не требуется.
