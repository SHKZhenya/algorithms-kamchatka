## Операции, период и риск дублирования

В `contract_obligations.json` внесены **43 позиции договора**. Осень–зима 2026 — календарный контекст срока контракта. **Четыре позиции № 28–31** прямо описывают противогололёдную обработку. В доступных строках договора № 0831 отдельная технология очистки снега и льда не подтверждена. Мойка перехода, обычный сбор мусора, погрузка, вывоз и обращение с отходами имеют собственные категории. Для дорожного сегмента показывается кандидат на механизированную противогололёдную обработку из позиции 28. Поле `approved_segment_ids` пустое до сверки с подписанным приложением.

По 18 строкам № 0831 получено **13 одноимённых объектов**, **1 общий коридор с различием описаний**, **2 возможных совпадения**, **1 близкая территория без установленного соответствия** и **1 объект без отдельного аналога**. 282 физических сегмента пилота лежат на общих картографических осях названных коридоров. Это совпадение на уровне документов и геометрических кандидатов. Одинаковая территория фактических заявок не подтверждена.

Для проезжей части оба набора содержат механизированное распределение материалов. Для тротуаров и остановок найдены совпадения на уровне типа работ, включая ручную россыпь. Отдельно в № 0902 есть плужная очистка, грейдирование уплотнённого снега, вырезка вала и ручная очистка тротуаров. Для перехода на Ленинградской, 49/1 найдены близкие операции по влажной уборке в двух закупках. № 0902 называет адрес, доступный предмет № 0831 даёт вид сооружения без адреса. [Перечень и виды работ № 0902](https://zakupki.kontur.ru/0138300000426000902)

У № 0831 указано окончание исполнения **25.12.2026**. У № 0902 заявлены работы начиная с 2026 года, но срок выполнения отсчитывается от заключения, с плановым окончанием **31.12.2028**. Более свежая доступная карточка указывает редакцию **18.11.2026** и приём заявок до **30.11.2026**. В более ранней копии виден другой срок подачи заявок; адресный перечень взят из доступной карточки с объектами, последнее исправленное приложение недоступно. Временное дублирование обработки возможно, если договор № 0902 вступит в исполнение до окончания № 0831 и заявки совпадут по месту, операции и времени. Фактическое дублирование и противоречия не подтверждены. [Карточка с историей редакций](https://gosanalitika.ru/zakupki/raboty-soderzhaniyu-0138300000426000902/)

## Подключение к карте

Выходы в `winter_audit/output/contract_scope/`:

- `contract_scope.geojson` — WGS84, по объектам и сегментам, с полями карточки. У справочных линий `physical_road_id` равен null. Поле `junction_anchor_segment_ids` означает лишь топологический ориентир.
- `object_links.json` — полный реестр № 0831, дополнительные случаи № 0902 и все сопоставленные ID.
- `contract_obligations.json` и `overlap_0831_0902.json` — работы и сравнение сроков, объектов и операций.
- `maplibre_popup.mjs` и `popup_fields.json` — обработчик и конфигурация карточки. Янтарный пунктир обозначает предварительную привязку. В карточке отдельно указаны стадия документа, статус ответственности, сторона договора и исполнитель на объекте. У позиции 14 нет геометрии.
- `responsibility_map.html` — отдельная интерактивная карта пилота, открывается локально без сервера. `responsibility_map.geojson` — тот же слой для ГИС. Серые линии обозначают сегменты с неизвестным ответственным. Янтарные линии обозначают привязки по извещению. Зелёный маркер на Ленинградской, 49/1 подтверждает оперативное управление сооружением по опубликованной записи имущественного реестра. Актуальность записи и зимний исполнитель на дату среза не установлены. Зелёных отрезков подтверждённых зимних работ по № 0831 нет.

После загрузки стиля карты импортировать модуль и передать загруженный GeoJSON. Обработчик показывает все совпавшие объекты по клику, что позволяет прочитать обе кандидатные записи у заездов к ПСРМЗ.

```js
import { addContractScope } from "./maplibre_popup.mjs";
const response = await fetch("./contract_scope.geojson");
if (!response.ok) throw new Error("Не удалось загрузить границы закупок");
const removeContractScope = addContractScope(map, maplibregl, await response.json());
```

Воспроизведение из корня репозитория после основного экспорта:

```bash
python3 -m winter_audit.contract_scope
python3 -m unittest winter_audit.test_contract_scope
```
